\# Enterprise Hybrid Healthcare Network Modernisation Project



\## Project Overview



This project simulates a multi-site healthcare organisation network using Cisco Packet Tracer. The environment includes a central datacentre, Type A branch sites, Type B remote sites, Microsoft Azure cloud services, Entra ID, Intune, Microsoft 365 and Google Cloud Platform.



The project aims to improve network performance, security, segmentation, monitoring, cloud integration and operational resilience through a modern hybrid network architecture.



\## Business Scenario



The organisation operates a central datacentre in Melbourne and multiple healthcare facilities across Australia. Branch sites require secure access to business applications, identity services and cloud-hosted platforms while maintaining strong cybersecurity controls and operational visibility.



\## Project Objectives



\* Design a hybrid enterprise network architecture

\* Build a multi-site healthcare network in Cisco Packet Tracer

\* Implement VLAN-based network segmentation

\* Configure routing and WAN connectivity

\* Simulate MPLS and site-to-site VPN connectivity

\* Integrate Microsoft Azure services

\* Integrate Google Cloud data services

\* Implement security controls and monitoring

\* Produce professional documentation for GitHub and LinkedIn
