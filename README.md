\# Enterprise Hybrid Healthcare Network Modernisation Project



\## Project Overview



This project simulates a multi-site healthcare organisation network using Cisco Packet Tracer. The design includes a main datacentre, Type A branch site, Type B remote site, Microsoft Cloud services and Google Cloud data services.



The purpose of this project is to demonstrate enterprise network design, hybrid cloud connectivity, VLAN segmentation, routing, security controls and network improvement planning.



\## Network Architecture



The network includes:



\- Microsoft Cloud: Entra ID, Intune, Microsoft 365, Azure services

\- Main Site Datacentre: Firewall, core network, servers

\- Type A Site: MPLS-connected branch site

\- Type B Site: Site-to-site VPN branch site

\- Google Cloud: Data platform, analytics, backup
